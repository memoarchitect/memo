# Laparoscopic sleeve gastrectomy workflow

A focused MEMO operational model of an illustrative laparoscopic sleeve
gastrectomy workflow. It is a modelling example, not a clinical protocol.

- `model/surgical_closure_workflow.sysml` is the public parent package.
- `model/catalog/` holds the canonical model elements.
- `model/viewpoints/` holds diagram views of that catalog.
