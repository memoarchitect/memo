# Foundations

The foundations sit underneath both axes. Every architecture layer and assurance
discipline builds on them, but none of them describes a device on its own. In
the figures, foundation elements are grey (core) or green (methodology); see the
[key](../index.md#how-to-read-the-figures).

| Area | What it holds |
| --- | --- |
| [Core](../../reference/areas/core.md) | the definitions shared by the rest of the ontology: the base types every element specialises, and the relationships used across layers and disciplines |
| [Artifacts](../../reference/areas/artifacts.md) | what kind of output a model-backed artifact is, and the controlled records and their lifecycle |
| [Viewpoints](../../reference/areas/viewpoints.md) | how model content is selected and presented for a stated concern, and the views that apply it |
| [Methodology](../../reference/areas/methodology.md) | how a project selects and governs its use of the ontology |
| [Rules](../../reference/areas/rules.md) | selectable constraints that a methodology chooses to apply to a model |
