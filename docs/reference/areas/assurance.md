# Assurance

**Source:** `src/assurance/` · **Namespace:** `memo::assurance`

Assurance defines requirements, and the disciplines that test the architecture
across every layer. Each discipline has its own page, which opens with the
question it answers. It then introduces the discipline's elements, shows how
they connect to the architecture, and lists the full inventory generated from
the source:
